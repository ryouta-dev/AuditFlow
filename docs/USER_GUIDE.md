# User guide

## Demonstration walkthrough

1. Open **Overview**. Review the sample results and open a recent inspection, or select **Checklists → New checklist** to start from scratch.
2. Name the checklist and first section. Add questions and decide which are required. For rated and choice questions, enter a score from 0 to 1 on every option to include the question in scoring.
3. Select **Publish checklist**. Use **New inspection** to choose the published checklist and version, then enter a title, site, and inspection date.
4. Answer the questions and add notes. Wait for the local save indicator before refreshing or closing the browser. The Progress panel shows how many required questions are answered and the score for applicable answers.
5. Select **Complete inspection**. Review any unanswered required questions. Use **Reopen** if you need to make an explicit correction and complete it again.
6. Select **View report**. Choose **Download Excel** for the summary, responses, and corrective actions worksheets. Choose **Print / Save PDF** and select **Save as PDF** in the browser’s print dialog.

## Findings and corrective actions

Select **Record finding** from an inspection, a question, or **Findings & CAPA**. Set the severity and record what you observed. Save, then add a corrective action with an owner, a due date, the root cause, and preventive work. For **Verified** and **Ineffective**, record the verification result. The workspace shows overdue open actions and keeps the status history.

## Work offline

Open the production app online once and check **Offline & sync** for **Available on this device**. Sign in and sync the records you need before going offline. While disconnected you can reopen the app, record answers, and view reports from records already on your device. Cloud accounts show **Completion pending** until the server accepts a local completion.

On reconnect, leave the app open while it syncs. If another device changed the same answer, open **Offline & sync** and compare both versions before selecting one. If the server has finalized the inspection, export pending changes before keeping the server version so you can review or re-enter the local notes later. Pending JSON exports contain inspection content. Store them securely. Browser storage removal can erase unsynced work.

## Navigation

Use the sidebar or Ctrl+K / Command+K to find checklists, inspections, and findings. The phone menu opens from the top left. Choose **English**, **Русский**, or **Қазақша** from the account menu, **Settings → Profile**, or the sign-in screen. The selected language applies to application screens, PDF reports, and Excel labels and is saved on this device.
